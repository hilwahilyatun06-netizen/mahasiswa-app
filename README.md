# Mahasiswa App

## Deskripsi
Proyek sederhana menggunakan Vite dan TypeScript untuk mempelajari interface, union type, fungsi generic, dan konfigurasi environment variable.

## Teknologi
- Vite
- TypeScript

## Fitur
- Interface Mahasiswa
- Union type Status: aktif, cuti, dan lulus
- Fungsi generic filterBy
- Konfigurasi nama aplikasi melalui VITE_APP_NAME

## Cara Menjalankan
1. Pastikan Node.js sudah terpasang.
2. Install dependensi:

   ```bash
   npm install
   ```

3. Buat file .env dan isi:

   ```env
   VITE_APP_NAME="Mahasiswa App"
   ```

4. Jalankan aplikasi:

   ```bash
   npm run dev
   ```

## Build
Untuk memeriksa dan membangun proyek:

```bash
npm run build
```
